What actually happens, in order
1 Shipment saved with Carrier = MAEU, POL = NLRTM, POD = USNYC.
2 CargoDesk looks up Carrier Agents for (MAEU, NLRTM) and (MAEU, USNYC) — see the Master Data mockup.
3 Each side is written as an ordinary Additional Party (Line Agent — Export / Import) — only if that role isn't already assigned on this shipment.
4 This card on Carrier Booking just displays whatever's actually assigned — same data Parties & Offices, Compliance screening, and the Customers Roles column all already read.
5 If no agent is registered for a given carrier+port yet, that side of the card simply reads "Not registered" — same as any unassigned role today.
6 Editing Carrier/POL/POD later re-runs the lookup — but only ever fills an empty slot, never overwrites a party that's already there, whether CargoDesk set it or a person did.
