Status update, verified 2026-08-25: this per-role provenance drill-down (shipment id + assignment date) was never built. GET /api/customers/:id/roles returns a bare array of role-name strings only — the shipped "After" panel renders just the badges above, with no source/date detail.

✓ The moment this customer is assigned as a Trucker on any shipment, "Trucker (Pre/On-carriage)" appears here automatically — same list, same picker-narrowing behavior, zero one ever has to open this page and click a box.
What stays identical either way: the role vocabulary (13 roles at the time this mockup was built — now 16, see status update below), the picker behavior (CustomerCombobox's role filter is always a soft suggestion — an operator can still reach any customer via "show all"), and every screen that reads a role today. Only where the role list itself comes from changes — a hand-kept flag vs. a live read of shipments already on file.

Status update, verified 2026-08-25: the "Current" panel's 13-checkbox grid is historically accurate for what it documented. The vocabulary has since grown to 16 roles (Line Agent Export/ Import v0.61.0, NVOCC v0.71.0) — those additions land under Service Providers in the "Proposed" panel's shipped equivalent, same as any other role.
