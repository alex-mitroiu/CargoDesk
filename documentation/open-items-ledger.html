FCL Coverage Audit — Gap ClosureTKT-6PO7SV

DocShipper shipping-glossary cross-check against CargoDesk's actual FCL schema/routes. Confirms the FCL core already matches or exceeds industry-standard definitions — these are the 5 real gaps it found (a 6th, the Master/House B/L split, turned out already shipped — see the reconciliation note below).

TKT-Q13HBD
Arrival Notice document (AN01)
One of the highest-frequency import documents — no dedicated doc type today, only the generic "Other."
✓ Done
TKT-V5KU48
Delivery Order document (DO01)
Cargo-release authorization to the destination trucker once the B/L is surrendered — routine, high-frequency, no dedicated type today.
✓ Done
TKT-QSUTQ7
Equipment condition capture at gate in/out (EIR)
container_events logs when a container moved, not its condition — no damage notation, photo, or interchange signature. A disputed detention charge usually comes down to proving condition.
✓ Done
TKT-V8MIG0
Chassis / drayage equipment tracking
movement_by captures the mode (Truck/Rail/Barge/Vessel) but nothing models the chassis itself — a real, separate cost and delay driver in US drayage.
✓ Done
TKT-U6IZCL
Landed-cost / duty estimate
Both inputs a duty estimate needs (declared_value, hs_code) already exist — nothing computes from them yet. CD01 declares the goods, doesn't cost them.
✓ Done
NVOCC Support — remaining scopeTKT-Q52B38

4 of 7 findings shipped in v0.71.0 (party role, licensing, booking shipper-of-record, Master B/L document). These 3 are the larger structural pieces deliberately not rushed through in that pass.

TKT-9O2B3T
Structural dual carrier/shipper split on the shipment record
carrier_code/principal_id are single-slot — no way to independently record "who we bought vessel capacity from" vs. "who we are as carrier-of-record to our own customer."
Medium
TKT-IB5IEX
Destination deconsolidation / two-stage cargo release
Real NVOCC destination handling is two distinct release events — carrier to the NVOCC's agent, then the NVOCC to the actual consignee. Only the first is modeled today.
Medium
TKT-UR1X17
NVOCC co-loading / cross-tariff reference
One NVOCC occasionally tenders cargo through another NVOCC's tariff rather than direct to a vessel operator — a real but less common pattern.
Low
