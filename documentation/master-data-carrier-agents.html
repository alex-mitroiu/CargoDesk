How this feeds a shipment: when a shipment's Carrier + Port of Load / Port of Discharge are saved, CargoDesk looks up the matching row here for each side and — only if that role isn't already assigned — adds Line Agent (Export) at the POL and Line Agent (Import) at the POD as ordinary Additional Parties. Nothing here is ever pushed onto a shipment that already has that role filled — this table only ever fills a gap, never overwrites a manual choice.
