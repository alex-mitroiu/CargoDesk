Deliberately off the dial

Three places coverage stayed put on purpose — chasing the number here would mean faking an integration or breaking a decision already made elsewhere in this suite.

Needs a live provider

ai.js's real tool-execution loop

The agentic loop only runs once a configured LLM actually replies with a tool_use block. Every gating, validation, and provider-branching path up to the real outbound fetch is tested — including a deliberate network failure via an RFC 2606 .invalid domain — but the loop itself needs a real, billed account on the other end.

Needs a real tenant

auth.js's SSO callback success path

Every guard before the token exchange is covered — disabled state, missing code/state, an unrecognized nonce. The exchange itself calls login.microsoftonline.com for real; reaching it needs an actual Azure AD app registration, not a fixture.

Would destroy live data

Sanctions sync / import routes

POST /api/sanctions/sync, /sync-csl, and /import-csv all replace the real synced OFAC/CSL dataset other tests match real sanctioned entities against. An existing test file had already declined to call them for exactly this reason — this pass just didn't relitigate it.

Verified, not assumed

Every one of these ran end-to-end from a freshly booted dev stack — not just each new file in isolation.
