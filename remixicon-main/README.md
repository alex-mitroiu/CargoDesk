# Remix Icon — vendored subset

Source: https://github.com/Remix-Design/RemixIcon (https://remixicon.com/)
License: Apache-2.0 (see the upstream repository's LICENSE file)

Same convention as `mingcute-icons-main/`: only the source SVGs actually used by
`src/components/primitives/Icon.jsx` are kept here as a reference — the icon
paths are self-contained in Icon.jsx and this folder is not used at runtime.
Remix fills the gaps MingCute doesn't cover (anchor, search, mail,
base-station, send-plane, upload/download); both sets share the same 24x24
filled-line style.
